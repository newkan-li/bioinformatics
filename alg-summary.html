序列比对的意义与类型概述p40Python
①解决什么问题/用途：本页说明序列比对是生物信息学中最常用的研究手段，用于比较两条或多条蛋白质/核酸序列，发现相似区域、保守位点，推断分子进化关系、共同功能模式，以及辅助结构预测和数据库搜索。
②核心思想：比对就像把两段或几段文字并排摆放，找出哪些字词相同、哪些被替换、哪些被插入或删除，从而判断它们是否来自同一“祖先文本”。
③主要步骤：双序列比对比较两条序列的相似区域和保守位点；多序列比对同时比较多个序列，寻找共同保守区域、位点和模式；蛋白质与核酸序列比较可探索表达框架；蛋白质与已知三维结构蛋白质比较可获得结构和折叠类型信息。
④复杂度或关键参数：本页为概念页，未给出具体复杂度；实际比对算法通常与序列长度、打分矩阵和空位罚分有关。
⑤优缺点/适用场景：比对能揭示进化与功能线索，但相似性不等于同源性，结果需结合实验验证；适用于序列分析、数据库搜索、结构预测等场景。

字符编辑操作与双序列比对p41Python
①解决什么问题/用途：本页引入字符编辑操作，用统一方式描述两条序列之间的匹配、删除、替换和插入，为双序列比对建立形式化基础。
②核心思想：把一条序列变成另一条序列，就像修改一篇文章：相同字符保留，不同字符替换，多出的字符删除，缺少的字符插入；空位字符“-”代表gap。
③主要步骤：定义四种编辑操作：Match(a,a)表示字符匹配；Delete(a,-)表示从第一条序列删除字符a或在第二条序列相应位置插入空位；Replace(a,b)表示以b替换a；Insert(-,b)表示在第一条序列插入空位或删除第二条序列中对应字符b。比较两条序列时，将这些操作组合起来。
④复杂度或关键参数：关键参数是每种编辑操作的代价或得分，如匹配得分、替换得分、空位罚分；不同参数会改变最优比对结果。
⑤优缺点/适用场景：编辑操作模型直观、通用，是Needleman-Wunsch和Smith-Waterman等算法的基础；但简单模型未考虑氨基酸理化性质差异，因此后续需要打分矩阵。

全局比对与局部比对递归算法p42Python
①解决什么问题/用途：本页给出全局比对和局部比对的递归算法，用于寻找两条序列在整体或局部区域上的最优比对。
②核心思想：全局比对像把两篇文章从头到尾逐字对齐；局部比对像只找出两篇文章中最相似的一段话，而不要求其余部分也匹配。
③主要步骤：全局比对Needleman-Wunsch设定初值后，按S(i,j)=max{S(i-1,j-1)+p(ai,bj), S(i-1,j)+p(ai,-), S(i,j-1)+p(-,bj)}填表，再回溯得到比对；局部比对Smith-Waterman类似，但得分小于0时置0，并从最高分单元回溯，只保留最佳局部亚区。
④复杂度或关键参数：时间复杂度O(mn)，空间复杂度O(mn)；关键参数包括匹配得分、错配得分和空位罚分。
⑤优缺点/适用场景：全局比对适合高度同源、长度相近的序列，如结构预测中的同源建模；局部比对适合寻找数据库中最匹配的亚区，能忽略不相关区域，但可能丢失整体关系信息。
∑ 公式：
全局比对递推 S(i,j)=max{ S(i-1,j-1)+p(a_i,b_j), S(i-1,j)+p(a_i,-), S(i,j-1)+p(-,b_j) }
局部比对递推 S(i,j)=max{ 0, S(i-1,j-1)+p(a_i,b_j), S(i-1,j)+p(a_i,-), S(i,j-1)+p(-,b_j) }

相似、同一与同源及直系/旁系同源p43Python
①解决什么问题/用途：本页澄清相似性、同一性与同源性的区别，并区分直系同源和旁系同源，避免把序列相似性直接误称为同源性。
②核心思想：相似性像两个人长得像，同一性像两人身份证号完全相同的位数，同源性像两人是否有共同祖先；长得像不一定有共同祖先，但很像时通常提示可能有共同祖先。
③主要步骤：计算两条序列相同字符比例得到同一性百分比；根据序列相似性推测共同进化历程和相似生物学功能；进一步区分直系同源（不同物种间由共同祖先基因垂直演化而来）和旁系同源（同一物种基因组内因基因复制产生）。
④复杂度或关键参数：同一性百分比计算简单，通常为O(n)；关键参数是比对长度、空位处理和相同字符判定标准。
⑤优缺点/适用场景：同一性百分比直观，但不能直接等同于同源性；高相似性可提示同源和功能相似，但结论必须经过实验验证。适用于基因/蛋白质功能注释和进化分析。

序列比对打分目的与打分矩阵概念p44Python
①解决什么问题/用途：本页说明序列比对需要合理打分，尤其是蛋白质序列中不同氨基酸替换代价差异很大，因此需要打分矩阵。
②核心思想：简单模型把所有不同字符替换都看成一样坏，就像考试时把写错一个字和写错一个完全无关的词都扣同样分；实际上，理化性质相近的氨基酸互相替换更可能不破坏功能，应给较高分。
③主要步骤：先定义简单代价模型，相同得正分、不同得负分；再引入替换矩阵，根据氨基酸理化性质和进化替换频率，为每对氨基酸设定得分；保守替换得分高于非保守替换。
④复杂度或关键参数：打分矩阵查表为O(1)；关键参数是矩阵类型，如BLOSUM、PAM，以及空位罚分。
⑤优缺点/适用场景：简单模型实现容易但生物学意义弱；打分矩阵更准确，适合蛋白质远缘同源检测和数据库搜索，但矩阵选择会影响结果，需要根据序列相似程度选择合适矩阵。

PAM打分矩阵与PAM值选择p46Python
①解决什么问题/用途：PAM打分矩阵用于蛋白质双序列比对中给氨基酸替换打分，帮助判断两条序列的相似性和进化关系。
②核心思想：PAM1表示每100个残基发生1次可接受突变的进化距离，PAM250表示每100个残基发生250次突变。通俗类比：像用不同倍数的放大镜看家族照片，亲缘近的用低倍镜（低PAM），亲缘远的用高倍镜（高PAM）。
③主要步骤：根据两条序列的相似度（identity百分比）选择PAM矩阵；相似度≥85%选PAM1~PAM50，≥60%选PAM100~PAM150，更远选PAM250。
④复杂度或关键参数：关键参数是PAM值（进化距离）和序列相似度阈值。
⑤优缺点/适用场景：PAM基于突变数据，适合亲缘关系较近到中等的序列；对远缘序列可能不够敏感，且矩阵构建依赖特定数据集。
∑ 公式：
PAM进化距离定义 PAMn：每100个残基发生n次可接受突变的进化距离
PAM值选择原则 亲缘关系近 → 低PAM值（如PAM100~PAM150）；亲缘关系远 → 高PAM值（如PAM250）

BLOSUM打分矩阵的构建与特点p47Python
①解决什么问题/用途：BLOSUM打分矩阵用于蛋白质序列比对打分，尤其适合寻找远缘同源序列。
②核心思想：基于BLOCKS数据库中保守序列模块构建，通过设置最小相同残基百分比整合序列片段，避免重复计数。通俗类比：像统计一个班级里同学之间互相代答问题的频率，只统计关系足够近的小组，避免重复统计同一对人。
③主要步骤：从BLOCKS数据库提取保守模块；按相同残基百分比聚类；统计氨基酸替换频率并计算对数 odds 得分；生成BLOSUM80、BLOSUM62等矩阵。
④复杂度或关键参数：关键参数是BLOSUM编号（如80、62、45），编号越大表示序列越相似、进化距离越近。
⑤优缺点/适用场景：BLOSUM62是默认通用矩阵，适合大多数蛋白质比对；BLOSUM80适合近缘序列，BLOSUM45适合远缘序列。相比PAM，BLOSUM更基于局部保守块，对远缘序列更敏感。

仿射空位罚分与dotplot算法p49Python
①解决什么问题/用途：仿射空位罚分用于更真实地模拟序列比对中的插入/缺失；dotplot算法用于直观展示两条序列的相似区域。
②核心思想：仿射空位罚分公式g(k)=a+b×k，a为起始空位罚分，b为延伸空位罚分，打开空位代价高、延伸代价低。通俗类比：像开车上高速，起步收费高，之后每公里收费低。dotplot则像把两条序列分别放在横纵坐标，相同字符处打点，形成对角线图案。
③主要步骤：仿射罚分：给定空位长度k，计算a+b×k；dotplot：构建m×n矩阵，逐对比较字符，相同则标记，最后观察对角线。
④复杂度或关键参数：仿射罚分O(1)；dotplot构建O(mn)，空间O(mn)。关键参数a、b、k。
⑤优缺点/适用场景：仿射罚分更符合生物学实际，广泛用于动态规划比对；dotplot直观但只能显示相同片段，不能提供统计学显著性，适合初步观察序列结构。
∑ 公式：
仿射空位罚分 g(k)=a+b×k
仿射空位罚分示例 a=-4，b=-3，k=某空位数量 → 总罚分= -4 + (-3)×k

dotplot算法特点与动态规划算法p50Python
①解决什么问题/用途：介绍dotplot的局限，并引入动态规划算法进行全局和局部序列比对。
②核心思想：dotplot只能显示相同片段，不能给出统计学相似性；动态规划通过填表寻找最优比对路径。全局比对（Needleman-Wunsch）要求两条序列全长对齐；局部比对（Smith-Waterman）只找最佳相似片段。通俗类比：全局像把两篇文章从头到尾逐字对齐；局部像只找两篇文章中最相似的一段。
③主要步骤：初始化得分矩阵；按递推公式填充矩阵，考虑匹配、错配和空位；全局取右下角为最优，局部取全矩阵最大值为最优；回溯得到比对路径。
④复杂度或关键参数：时间和空间复杂度均为O(mn)。关键参数：匹配得分、错配罚分、空位罚分。
⑤优缺点/适用场景：全局比对适合长度相近、整体相似的序列；局部比对适合长度差异大、只有局部相似的序列。动态规划精确但计算量大，不适合超大规模数据库搜索。
∑ 公式：
全局动态规划算法 Needleman-Wunsch算法：用于发现两条序列全局水平上的相似性
局部动态规划算法 Smith-Waterman算法：用于发现局部水平上的相似性

BLAST算法原理与特点p52伪代码/自然语言
①解决什么问题/用途：解决动态规划精确比对在大规模序列数据库搜索中耗时过长的问题，用于快速寻找查询序列与数据库中序列的最佳局部比对。
②核心思想：先用短片段（seed/词）快速定位潜在匹配区域，再向两端延伸并评估显著性。通俗类比：像在图书馆找书，不逐页读完整本书，而是先根据关键词找到可能相关的书架，再仔细翻阅这些书。
③主要步骤：1）编译查询序列，生成固定长度词列表；2）扫描数据库，找到与词匹配的序列记录；3）以匹配词为中心向两端延伸，计算得分；4）保留高分片段，并用统计模型评估期望值E。
④复杂度或关键参数：关键参数包括词长word_len（默认3）、得分阈值T（默认11）、X（默认1）等；相比动态规划，速度大幅提升。
⑤优缺点/适用场景：优点是速度快、灵敏度较高，适合大规模数据库相似性搜索；缺点是可能漏掉短而弱的相似性，对远缘关系不如更敏感方法。

数据库设计与范式p317伪代码/自然语言
①解决什么问题/用途：本页解决数据库设计中数据冗余、更新异常和一致性问题，通过规范化（范式）指导建立结构良好的关系表。
②核心思想：规范化就像整理衣柜：1NF要求每个格子只放一件衣服（原子值）；2NF把同类衣服移到独立抽屉（消除部分依赖）；3NF确保每件衣服只由衣柜编号决定位置（消除传递依赖）。
③主要步骤：先检查1NF，保证每列原子值并设主键；再检查2NF，找出非主属性对复合主键的部分依赖，拆表并用主键-外键关联；最后检查3NF，找出非主属性间的传递依赖，继续拆表。
④复杂度或关键参数：伪代码给出时间复杂度O(n*m)，n为行数、m为列数；关键参数是主键、外键、函数依赖。
⑤优缺点/适用场景：优点是减少冗余、提高一致性、便于维护；缺点是过度规范化可能导致表过多、查询连接开销大。适用于事务型数据库设计，如文献数据库。
∑ 公式：
第一范式（1NF）条件 ∀列 c ∈ 表 T，c 的每个取值均为原子值；且 T 有主键 K
第二范式（2NF）条件 T ∈ 1NF 且 ∀非主属性 A，A 完全函数依赖于主键 K，即不存在 K 的真子集 K' 使 K' → A
第三范式（3NF）条件 T ∈ 2NF 且 ∀非主属性 A，A 直接依赖于主键 K，即不存在非主属性 B 使 K → B 且 B → A

①解决什么问题/用途：本页介绍4D核体计划和Hi-C技术流程。4D核体计划旨在定义细胞核结构与基因组组织的术语和数据类型规范，建立细胞核的全面综合模型；Hi-C用于检测染色质三维空间相互作用。
②核心思想：Hi-C通过甲醛交联固定染色质空间构象，酶切后连接空间上邻近的DNA片段，再通过高通量测序检测连接产物，从而推断染色质的三维接触频率。通俗类比：就像把一团毛线先固定、剪断、再重新连接，然后通过分析哪些线头连在一起，推断毛线原来的缠绕方式。
③主要步骤：甲醛交联→分离染色质→酶切→生物素标记→连接DNA→纯化→移除末端生物素→片段化→生物素拉下→高通量测序→比对→构建接触矩阵。
④复杂度或关键参数：Hi-C数据处理包括比对（bowtie2）、过滤、接触矩阵构建和归一化；关键参数包括酶切效率、测序深度和分辨率。
⑤优缺点/适用场景：Hi-C可全基因组检测染色质相互作用，分辨率可达kb级，但数据量大、分析复杂；适用于三维基因组学、基因组组装和宏基因组物种聚类。

新技术相互关系与生物信息学挑战p348Python
①解决什么问题/用途：本页总结新技术之间的相互关系及生物信息学挑战，包括第三代单分子测序、单细胞测序、宏基因组测序和Hi-C技术的相互辅助，以及高通量测序带来的数据存储、比较分析和可视化挑战。
②核心思想：不同技术可以互补：第三代单分子测序免扩增提高单细胞测序精度；单细胞测序辅助宏基因组发现新细菌；Hi-C辅助宏基因组组装，将contigs按物种聚类。通俗类比：就像不同工具协同工作，望远镜看远，显微镜看细，结合起来能更全面理解世界。
③主要步骤：以Hi-C辅助宏基因组组装为例：获取Hi-C接触信号→计算contigs间接触频率→构建相似性矩阵→谱聚类（如SpectralClustering）→将contigs按物种分组。
④复杂度或关键参数：Hi-C辅助组装关键参数包括接触矩阵的归一化、聚类算法和簇数；数据存储挑战包括原始图像数据可舍弃，序列数据需长期保存。
⑤优缺点/适用场景：多技术整合能提高组装和发现能力，但计算复杂、数据管理困难；适用于复杂微生物组、单细胞基因组和三维基因组研究。
