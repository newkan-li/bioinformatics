0. 先下载示例代码

示例合集里每段都可展开「🐍 Python 学习版」。也可打包下载全部可运行脚本：⬇ bioinfo-python-examples.zip

1. 安装 Python（三条路线，任选其一）

A. 推荐：Anaconda / Miniconda（自带科学计算包，适合生物信息） 
# 下载安装 Miniconda（Linux x86_64）
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh    # 一路回车/yes，最后 source ~/.bashrc
conda --version

图形界面用户可直接装 Anaconda（Windows/macOS 有安装包），自带 conda 与常用库。

B. venv（系统已有 Python3 时，最轻量） 
python3 --version          # 建议 3.8+
python3 -m venv bioinfo    # 建虚拟环境
source bioinfo/bin/activate  # Windows: bioinfo\Scripts\activate
python -m pip install --upgrade pip
C. 直接用系统 Python（不推荐，容易污染环境） 
sudo apt update && sudo apt install -y python3 python3-pip

2. 创建并使用环境（conda）

conda create -n bioinfo python=3.10 -y
conda activate bioinfo        # 退出：conda deactivate
python --version

3. 安装生物信息常用包

# 基础科学计算 + 生物信息
pip install numpy scipy pandas matplotlib scikit-learn
pip install biopython              # 序列/比对/Phylo
pip install hmmlearn               # 隐马尔可夫模型（HMM）
pip install pysam                  # 读取 SAM/BAM（测序比对结果）
pip install statsmodels            # 统计模型
# 可选：序列比对与系统发生常用命令行工具
conda install -c bioconda -y blast mafft iqtree samtools bcftools

国内加速：pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名

4. 编辑器与运行

  • 轻量：VS Code + Python 扩展（可设断点单步调试）。
  • 交互/教学：jupyter notebook 或 jupyter lab；或 ipython。
  • 运行脚本：python demo.py；参数：python demo.py input.fa。

5. 单步调试（pdb / VS Code）

# 方式一：命令行 pdb
python -m pdb demo.py
(Pdb) b demo.py:20      # 在第20行设断点
(Pdb) r                 # 运行到断点
(Pdb) n                 # 单步(不进入函数) / s 进入函数
(Pdb) p var             # 查看变量 var
(Pdb) l                 # 查看当前代码
(Pdb) c                 # 继续到下一个断点 / q 退出
# 方式二：代码内断点
def gc(seq):
    breakpoint()        # Python3.7+，运行到这里暂停进入 pdb
    return (seq.count("G")+seq.count("C"))/len(seq)

VS Code：行号左侧点一下设红点 → F5 启动调试 → F10 单步跳过、F11 单步进入、左侧“变量/监视”看中间值。

6. 常见报错速查

ModuleNotFoundError: No module named 'Bio'

没装包或装错环境。确认已 conda activate bioinfo，再 pip install biopython；注意包名是 biopython，导入名是 Bio。

pip 安装很慢 / 超时

换源：pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名；或设置 pip config set global.index-url ...。

SSL: CERTIFICATE_VERIFY_FAILED

更新 pip/证书：python -m pip install --upgrade pip；或临时加 --trusted-host pypi.org --trusted-host files.pythonhosted.org（仅应急）。

Permission denied

别用 sudo pip；在虚拟环境里装，或加 --user。sudo chown -R $USER ~/miniconda3 修复权限。

SyntaxError / IndentationError

Python 用缩进（4 空格）而非花括号；检查中英文标点、冒号、括号是否配对；python -m py_compile demo.py 可快速定位语法错误。

'python' 不是命令（Windows）

用 py 或把 Python 加入 PATH；conda 用户先 conda activate bioinfo。

conda 命令找不到

重新打开终端或 source ~/.bashrc；检查安装路径是否加进 PATH。

7. 常用包对照（教学示例用）

  • Biopython：序列读写（SeqIO）、双序列比对（pairwise2）、系统发育（Phylo）、Entrez 检索。
  • hmmlearn：HMM 前向/后向/Viterbi（对应教材第十二章）。
  • scikit-learn：聚类、PCA、SVM、朴素贝叶斯（第十二章）。
  • numpy/pandas/matplotlib：数值、表格、绘图。
  • pysam：SAM/BAM/VCF（第十四章测序数据处理）。
