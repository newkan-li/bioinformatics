第三章 序列比对原理

编辑操作定义p41
Match(a,a)；Delete(a,-)；Replace(a,b)；Insert(-,b)
a、b为字符；'-'为空位字符(gap)。Match表示匹配，Delete表示删除/插入空位，Replace表示替换，Insert表示插入空位/删除。
全局比对递推p42
S(i,j)=max{ S(i-1,j-1)+p(a_i,b_j), S(i-1,j)+p(a_i,-), S(i,j-1)+p(-,b_j) }
S(i,j)为前i个与j个字符的最优得分；a_i、b_j为序列字符；p为打分函数；'-'为空位。
局部比对递推p42
S(i,j)=max{ 0, S(i-1,j-1)+p(a_i,b_j), S(i-1,j)+p(a_i,-), S(i,j-1)+p(-,b_j) }
加入0项使局部比对可从任意位置重新开始，得分为负时归零。
DNA打分矩阵示例p45
M(A,A)=M(G,G)=M(C,C)=M(T,T)=0.99；M(A,G)=M(G,A)=0.006；M(A,C)=M(C,A)=0.002 等
对角线为相同碱基匹配得分；非对角线为不同碱基替换得分，转换与颠换得分不同。
氨基酸打分矩阵概念p45
s(a_i,b_j) 依据氨基酸残基理化性质相似性取值
s为氨基酸替换得分；相似残基替换得分高于不相似残基替换。
PAM进化距离定义p46
PAMn：每100个残基发生n次可接受突变的进化距离
PAM1表示每100个残基发生1次可接受突变；PAM250表示每100个残基发生250次突变
PAM值选择原则p46
亲缘关系近 → 低PAM值（如PAM100~PAM150）；亲缘关系远 → 高PAM值（如PAM250）
高PAM值相当于容许更高的噪声背景
BLOSUM编号含义p47
BLOSUMx：由相同残基≥x%的序列模块产生
如BLOSUM80由相同残基≥80%的序列模块产生；BLOSUM62由相同残基≥62%的聚合序列产生
BLOSUM与PAM编号趋势对比p47
BLOSUM编号越大 → 进化关系越近；PAM编号越大 → 进化关系越远
两者编号方向相反
序列一致性百分比p48
Identities = 相同残基数目 / 比对总长度 × 100%
PAM250示例：36/52（69%）；BLOSUM62示例：36/53（68%）
序列相似性百分比p48
Positives = 相同和相似残基总数 / 比对总长度 × 100%
PAM250示例：47/52（90%）；BLOSUM62示例：47/53（89%）；“+”表示可能发生相似替换
仿射空位罚分p49
g(k)=a+b×k
a为起始空位罚分，b为空位延伸罚分，k为空位数量；打开空位代价较高，延伸空位代价较低
仿射空位罚分示例p49
a=-4，b=-3，k=某空位数量 → 总罚分= -4 + (-3)×k
页中示例某比对共罚23分
全局动态规划算法p50
Needleman-Wunsch算法：用于发现两条序列全局水平上的相似性
由Needleman和Wunsch于1970年提出
局部动态规划算法p50
Smith-Waterman算法：用于发现局部水平上的相似性
由Smith和Waterman于1981年提出
动态规划得分矩阵递推p51
M(i,j)=max{ M(i-1,j-1)+D(i,j), M(i-1,j)+D(i-1,j), M(i,j-1)+D(i,j-1) }
M为得分矩阵；D为记分函数；相同+2、不相同-1、插入空位-1
得分矩阵初始化p51
M(0,0)=0
从M(0,0)开始按递推公式迭代计算各元素
M(1,1)计算示例p51
M(1,1)=max{ M(0,0)+D(1,1), M(0,1)+D(0,1), M(1,0)+D(1,0) } = max{ -1, -2, -2 } = -1
序列s=“acgctg”，t=“catgt”；M(0,0)+D(1,1)=0+(-1)=-1
局部比对高分片段对阈值p52
H ≥ S
H为以匹配词为中心向两端延伸得到的局部比对得分，S为设定的阈值分数
BLAST词匹配p52
w = 固定长度字段（词）
w为查询序列编译生成的短片段（seed/word），用于快速扫描数据库
线性空位罚分p54
Gap cost = g_o + g_e × L
g_o为开放罚分（默认11），g_e为延伸罚分（默认1），L为空位长度
比对得分p54
Score = Σ s(a_i, b_j) - Gap cost
s(a_i,b_j)为残基/碱基匹配得分，Gap cost为空位罚分
PSI-BLAST阈值p55
E-value < Threshold
期望值小于PSI-BLAST Threshold的序列被纳入多序列比对以构建PSSM矩阵
PHI-BLAST模式匹配p55
Pattern: GXW...
GXW为示例模式，X表示任意氨基酸，PHI-BLAST寻找符合该模式且与查询相似的序列
多序列比对动态规划p56
D(i_1, i_2, ..., i_k) = max{ D(i_1-1, ..., i_k-1) + s(...), ... }
k为序列条数，D为k维打分矩阵，s为匹配得分，回溯路径代表比对结果
渐进式比对p56
比对 = 逐步合并两两比对
大多数工具采用渐进式算法，先比对最相似序列，再逐步加入其他序列

第十二章 统计学习与推理

数据集表示p258
(y_i, x_i), i=1,…,n，x_i∈ℝ^m
y_i为因变量，x_i为m维自变量；若样本顺序不可变动，则为纵向数据或有序样本
回归损失函数p259
L(y,f(x,w))=(y−f(x,w))^2
平方损失，用于回归问题
密度估计损失函数p259
L(p(x,w))=−ln p(x,w)
负对数似然损失，用于密度估计
经验风险最小化p259
R_emp(w)=1/n Σ_{i=1}^n L(y_i,f(x_i,w))
用样本平均损失近似期望风险；两类判别时即训练错误率，平方损失时即平方训练误差
结构风险最小化界p261
R(w) < R_emp(w) + Φ(h/n)
R(w)为实际风险，R_emp(w)为经验风险，Φ(h/n)为置信范围，h为VC维，n为样本数
观测值分解p263
y_i = μ + e_i
y_i为观察值，μ为总体平均数，e_i为误差
最小二乘目标函数p263
Q = Σ (y_i − μ)^2
对总体平均数μ的最小二乘估计，最小化Q
总体平均数的最小二乘估计p263
μ̂ = 1/n Σ y_i
令dQ/dμ=0得Σ(y_i−μ)=0，故算术平均数是总体平均数的最小二乘估计
多项分布似然函数p264
L(p1,p2,p3)=50!/(12!24!14!) p1^12 p2^24 p3^14，其中 p1+p2+p3=1
p1,p2,p3为三类概率；12,24,14为观测频数；50为总样本数
连续型独立样本似然函数p264
L(θ)=∏ f(yi;θ)
θ为参数；f(yi;θ)为第i个观测的概率密度；∏表示连乘
正态分布似然函数（含密度形式）p264
L(μ,σ²)=∏ (1/(√(2π)σ)) exp[-(yi-μ)²/(2σ²)]
yi~N(μ,σ²)；μ为均值；σ²为方差
中心化变换p265
x'ij = xij - x̄j
xij为原始指标值；x̄j为第j个指标的均值；x'ij为中心化后的值
马氏距离p266
d²(M) = (xi - xj)' Σ⁻¹ (xi - xj)
xi,xj为两个样品的p维向量；Σ为协差阵；Σ⁻¹为协差阵的逆
兰氏距离p266
d(L) = ∑ |xia - xja| / (xia + xja)
xia,xja为样品i和j在第a个指标上的值；要求xij>0；求和遍及所有指标
夹角余弦p266
cosθ = ∑ xia xja / sqrt(∑ xia²) sqrt(∑ xja²)
xia,xja为样品i和j在第a个指标上的值；求和遍及所有指标
最短距离法类间距离p267
Dij = min{ dab | a∈Gi, b∈Gj }
Dij为类Gi与Gj的距离；dab为样品a与b的距离；Gi,Gj为两个类
合并后新类与其它类的距离递推p267
Dkr = min{ Dki, Dkj }
Gr为Gi与Gj合并后的新类；Gk为任一类；Dkr为Gk与Gr的距离
标准化变换p268
(xij)' = (xij - x̄j) / sj
xij为原始观测值；x̄j为第j个指标均值；sj为第j个指标标准差
样本方差p268
sj² = ∑ (xij - x̄j)² / (n-1)
n为样本数；x̄j为第j个指标均值
特征方程p268
|R - λI| = 0
R为样本相关系数矩阵；λ为特征根；I为单位矩阵
主成分方差贡献率p268
∑_{i=1}^m λi / ∑_{i=1}^p λi ≥ 0.8
λi为第i个特征根；m为主分量个数；p为原始变量个数
组重心线性组合p269
ȳ(A) = ∑ ci X̄i(A)，ȳ(B) = ∑ ci X̄i(B)
ci为判别系数；X̄i(A),X̄i(B)分别为A组和B组第i个指标均值
两组间离差p269
[ȳ(A) - ȳ(B)]²
ȳ(A),ȳ(B)分别为A组和B组的重心
组内离散程度p269
∑ [yi(A) - ȳ(A)]²
yi(A)为A组第i个样品的判别得分；ȳ(A)为A组重心
判别函数F检验p270
F = (组间差异 / 组内差异) ~ F(p, n_A+n_B-p-1)
n_A、n_B为两类样本数，p为变量数；F值超过临界值则判别函数显著
朴素贝叶斯分类准则p271
c* = argmax_{c_i} P(c_i)P(X|c_i)
P(X)对所有类别相同，分类时只需比较P(c)P(X|c)或P(X|c)
属性条件独立假设p271
P(X|c) = ∏_{i=1}^{d} P(x_i|c)
在给定类别c下，各属性x_i相互独立
类先验估计p271
P(c) ≈ |D_c| / |D|
类先验未知时，可用类样本比例近似
类别N后验概率计算p272
P(N|X) = P(N)P(Sunny|N)P(Hot|N)P(High|N)P(Weak|N) / P(X) = (5/14)×(3/5)×(2/5)×(4/5)×(2/5) / P(X) = 0.0274 / P(X)
测试样本X=(Sunny,Hot,High,Weak)，类别N
类别P后验概率计算p272
P(P|X) = P(P)P(Sunny|P)P(Hot|P)P(High|P)P(Weak|P) / P(X) = (9/14)×(2/9)×(2/9)×(3/9)×(6/9) / P(X) = 0.007039 / P(X)
测试样本X=(Sunny,Hot,High,Weak)，类别P
后验概率分类决策p272
若 P(N|X) > P(P|X)，则 X 属于类别 N
按后验概率最大原则分类
HMM模型参数p273
λ = (A, B, π)
A为状态转移概率分布，B为观察符号概率分布，π为初始状态概率分布；N为状态数，M为观察符号数
观察序列生成p273
O = (o_1, o_2, …, o_T)
根据π选择初始状态q_1，再按b_i选择观察o_t，按A转移状态，重复至T
状态转移矩阵Ap274
A = [a_{ij}]_{3×3}，例如 a_{Sunny,Sunny}=0.500, a_{Sunny,Cloudy}=0.250, a_{Sunny,Rainy}=0.250; a_{Cloudy,Sunny}=0.375, a_{Cloudy,Cloudy}=0.250, a_{Cloudy,Rainy}=0.375; a_{Rainy,Sunny}=0.1…
状态为Sunny、Cloudy、Rainy；观察为Dry、Dryish、Damp、Soggy
穷举法评估观察序列概率p274
P(O|λ) = Σ_{Q} P(O,Q|λ) = Σ_{q_1,…,q_T} π_{q_1} b_{q_1}(o_1) ∏_{t=2}^{T} a_{q_{t-1}q_t} b_{q_t}(o_t)
对所有可能状态序列Q求和，用于HMM评估问题
穷举法计算量p275
约 N^T(T-1) 次乘法，N(N-1)(T-1) 次加法
N为状态数，T为观察序列长度；指数复杂度
后向概率定义p275
β_t(i) = P(o_{t+1}, o_{t+2}, …, o_T | q_t = S_i, λ)
在模型λ下，t时刻处于状态S_i，从t+1到T的观察序列为o_{t+1},…,o_T的概率
后向算法初始化p275
β_T(i) = 1, 1 ≤ i ≤ N
后向算法初始条件
后向算法递推p275
β_t(i) = Σ_{j=1}^{N} a_{ij} b_j(o_{t+1}) β_{t+1}(j)
从t+1到T的后向概率递推公式
HMM模型定义p276
λ=(A,B,π)
A为状态转移概率矩阵，B为观测概率/发射概率矩阵，π为初始状态概率分布
观测序列p276
O=(o1,o2,…,oT)
长度为T的观测序列
状态序列p276
Q=(q1,q2,…,qT)
与观测序列对应的隐状态序列
Viterbi递推变量定义p276
δt(i)=max_{q1,…,qt-1} P(q1,…,qt-1, qt=Si, o1,…,ot | λ)
δt(i)表示在时刻t处于状态Si，且观测到o1…ot的最大路径概率；Si为第i个状态
Viterbi递推更新p277
δt(j)=max_i [ δt-1(i) · a_ij ] · b_j(ot)
δt(j)为时刻t状态Sj的最大路径概率；a_ij为从状态Si转移到Sj的概率；b_j(ot)为状态Sj发射观测ot的概率
Viterbi回溯指针p277
ψt(j)=argmax_i [ δt-1(i) · a_ij ]
ψt(j)记录时刻t状态Sj的最优前驱状态索引
第三天Sunny状态概率示例p277
δ3(Sunny)≈7.088×10^-4
以天气-海草湿度模型为例，第三天天气为Sunny且海藻状态为Soggy的最大路径概率
第三天Cloudy状态概率示例p277
δ3(Cloudy)≈5.581×10^-3
第三天天气为Cloudy且海藻状态为Soggy的最大路径概率，路径来自第二天Rainy
HMM独立事件序列概率p279
P(O|λ)=∏_{t=1}^{T} P(ot|λ)
当事件独立时，序列概率为各独立观测概率的乘积；O为观测序列，T为序列长度
newelm函数调用格式p280
net=newelm(PR,[S1 S2 … SNH],{TF1 TF2 … TFNI},BTF,BLF,PF)
PR为R×2维输入取值范围矩阵[Pmin Pmax]；[S1 S2 … SNH]为各层神经元个数；{TF1 TF2 … TFNI}为传输函数，默认tansig；BTF为训练函数，默认traingdx；BLF为权值和阈值学习函数，默认learngdm；PF为性能函数，默认mse
train函数调用格式p281
[net,tr,Y,E,Pf,Af]=train(NET,P,T,Pi,Ai,VV,TV)
net为训练后网络；tr为训练记录；Y为网络输出；E为误差矢量；Pf为训练终止时输入延迟状态；Af为训练终止时层延迟状态；NET为训练前网络；P为输入向量和矩阵；T为目标矩阵，缺省为0；Pi为初始输入延时，缺省为0；Ai为初始层延时，缺省为0；VV为验证矢量；TV为测试矢量
tansig传输函数p281
tansig(x)=2/(1+e^{-2x})-1
双曲正切S型传输函数，常用于神经网络隐含层
Elman网络输入特征维数p282
D=3×4=12（每阶4种碱基）→ 1~3阶共 4+4²+4³=84 维
D为编码特征维数；1~3阶核苷酸组成频率拼接
Elman隐层输出p282
h(t)=tansig(W₁·x(t)+b₁)
h为隐层输出，x为输入，W₁、b₁为隐层权值与偏置，tansig为双曲正切S型函数
Elman输出层p282
y(t)=purelin(W₂·h(t)+b₂)
y为网络输出，W₂、b₂为输出层权值与偏置，purelin为线性传递函数
训练目标p282
min E=Σ(y(t)-ŷ(t))²，E≤0.0001，迭代≤3000
E为误差平方和，ŷ为期望输出
线性可分SVM决策函数p283
M(x)=sgn(w*·x+b*)=sgn(Σᵢ αᵢ* yᵢ (xᵢ·x)+b*)
w*、b*为最优超平面参数；αᵢ*为Lagrange乘子；yᵢ∈{+1,-1}；xᵢ为支持向量
核函数SVM决策函数p283
M(x)=sgn(Σᵢ αᵢ* yᵢ K(xᵢ,x)+b*)
K(xᵢ,x)为核函数，将样本映射到高维特征空间F使其线性可分
约束二次优化p283
max W(α)=Σᵢ αᵢ - ½ Σᵢ Σⱼ αᵢ αⱼ yᵢ yⱼ K(xᵢ,xⱼ)，s.t. Σᵢ αᵢ yᵢ=0，0≤αᵢ≤C
α为Lagrange乘子，C为惩罚参数
核矩阵存储量p284
S≈n²×8 字节（n>4000 时约 128 MB）
n为样本数；核函数矩阵为n×n，双精度8字节
对偶问题分解p284
max W(α)=Σᵢ αᵢ - ½ Σᵢ Σⱼ αᵢ αⱼ yᵢ yⱼ K(xᵢ,xⱼ)
将原问题分解为子问题循环迭代求解
KKT条件（非支持向量）p284
αᵢ=0 ⇒ 样本不影响解，可剔除
块算法依据：去掉Lagrange乘子为零的样本不影响最优解
SVM计算复杂度p285
T(n)=O(n²) 或更高
n为训练样本数；大样本时优化算法难以处理子问题规模与迭代次数
回归性能评价（均方误差）p285
MSE=(1/m)Σᵢ(yᵢ-ŷᵢ)²
m为样本数；SVR缺乏显式表达式，多通过MSE与参比模型比较

焦磷酸测序发光反应p331

双碱基编码探针结构p335
探针 = [荧光标记]-(第1位碱基)(第2位碱基)-(第3~5位随机碱基)-(第6~8位通用碱基)
第1、2位为编码区决定荧光颜色；第3-5位随机；第6-8位可与任意碱基配对
双碱基编码解码p336
若已知参考序列某位置碱基 b_i，则 b_{i+1} = decode(c_i, b_i)
c_i为第i次连接测得的颜色编码；通过双碱基编码矩阵由前一碱基和颜色推出下一碱基；每个碱基被读取两次，准确度>99.94%

C + HSO₃⁻ → U + HSO₃⁻（未甲基化胞嘧啶）；5mC + HSO₃⁻ → 5mC（甲基化胞嘧啶不变）

y_ijk为观测值，μ为总均值，α_i为因素A效应，β_j为因素B效应，(αβ)_ij为交互效应，ε_ijk为随机误差。
