简答4. 简述多序列比对（MSA）与两两序列比对的主要区别，并说明多序列比对中常用的两种算法策略。
参考答案
主要区别：两两序列比对只比较两条序列，目标是寻找两条序列间的最优或近似最优比对；多序列比对同时比较三条及以上序列，目标是使所有序列在相同列上具有同源/相似关系，通常用于发现保守位点、构建系统发育树和进行保守结构域分析。常用策略：1）渐进式比对，如 Clustal 系列，先两两比对构建指导树，再按树顺序逐步加入序列；2）迭代式/一致性方法，如 MUSCLE、T-Coffee 等，通过反复优化或整合多种比对信息提高准确性。
算法设计5. 请写出利用动态规划进行两条序列全局比对（Needleman-Wunsch）的伪代码，包括得分矩阵填充和回溯过程。假设匹配得分 +1，错配得分 -1，空位罚分 -2。
参考答案
输入：序列 A[1..m]，B[1..n]；匹配得分 s(a,b)，空位罚分 g。
1. 初始化矩阵 F[(m+1) x (n+1)]
2. F[0][0] = 0
3. for i = 1 to m: F[i][0] = i * g
4. for j = 1 to n: F[0][j] = j * g
5. for i = 1 to m:
6. for j = 1 to n:
7. match = F[i-1][j-1] + s(A[i], B[j])
8. delete = F[i-1][j] + g
9. insert = F[i][j-1] + g
10. F[i][j] = max(match, delete, insert)
11. 回溯：从 i=m, j=n 开始，while i>0 or j>0:
12. 若 F[i][j] == F[i-1][j-1] + s(A[i],B[j])，则 A[i] 与 B[j] 配对，i--, j--
13. 否则若 F[i][j] == F[i-1][j] + g，则 A[i] 与空位配对，i--
14. 否则 B[j] 与空位配对，j--
15. 输出回溯得到的比对结果和得分 F[m][n]。
踩分点：初始化边界；递推公式包含匹配/错配、删除、插入三种情况；正确取最大值；回溯方向判断；输出比对结果。

复杂度7. 分析 Needleman-Wunsch 全局比对算法的时间复杂度和空间复杂度，并说明如何将空间复杂度优化到 O(min(m,n))。
参考答案
Needleman-Wunsch 需要填充 (m+1) x (n+1) 的得分矩阵，每个单元格计算一次，因此时间复杂度为 O(mn)。若保存完整矩阵用于回溯，空间复杂度为 O(mn)。优化方法：若只需比对得分而不需要具体比对结果，可只保留当前行和上一行，空间复杂度降为 O(min(m,n))；若仍需回溯比对结果，可采用 Hirschberg 分治算法，在 O(mn) 时间下将空间复杂度降至 O(min(m,n))。

算法设计12. 设计一个基于朴素贝叶斯分类器的算法，用于根据基因表达特征判断样本是否患病。请写出伪代码或流程。
参考答案
输入：训练集 D = {(x_i, y_i)}，其中 x_i 为基因表达向量，y_i ∈ {患病, 正常}；待分类样本 x。
1. 计算先验概率 P(y) = |D_y| / |D|，其中 D_y 为类别 y 的样本子集。
2. 对每个特征 j 和类别 y，计算条件概率 P(x_j | y)。若特征连续，假设服从高斯分布，估计均值 μ_{j,y} 和方差 σ^2_{j,y}。
3. 对于待分类样本 x，对每个类别 y 计算：
score(y) = log P(y) + Σ_j log P(x_j | y)
4. 返回使 score(y) 最大的类别 y 作为预测结果。
（可选：使用拉普拉斯平滑处理零概率。）
踩分点：1. 正确计算先验概率；2. 正确估计条件概率（连续特征用高斯分布）；3. 使用对数避免下溢；4. 返回最大后验概率类别。
算法设计13. 设计一个基于 HMM 和 Viterbi 算法识别 DNA 序列中 CpG 岛的算法流程（伪代码）。
参考答案
输入：DNA 序列 O = o_1, o_2, ..., o_T（观测为 A, C, G, T）；HMM 参数：初始概率 π，转移概率 A，发射概率 B。状态集：{CpG岛, 非CpG岛}。
1. 初始化：对于每个状态 s，δ_1(s) = π_s * B_s(o_1)，ψ_1(s) = 0。
2. 递推：对于 t = 2 到 T，对于每个状态 s：
δ_t(s) = max_{s'} [δ_{t-1}(s') * A_{s',s}] * B_s(o_t)
ψ_t(s) = argmax_{s'} [δ_{t-1}(s') * A_{s',s}]
3. 终止：P* = max_s δ_T(s)，s_T* = argmax_s δ_T(s)。
4. 回溯：对于 t = T-1 到 1，s_t* = ψ_{t+1}(s_{t+1}*)。
5. 输出隐藏状态序列 s_1*, s_2*, ..., s_T*，其中 CpG岛 状态对应的区域即为预测的 CpG 岛。
踩分点：1. 正确初始化；2. 递推公式正确（取最大并记录回溯指针）；3. 终止与回溯正确；4. 输出状态序列。
复杂度14. 分析 Viterbi 算法在隐马尔可夫模型（HMM）中的时间复杂度和空间复杂度。假设隐藏状态数为 N，观测序列长度为 T。
参考答案
时间复杂度：O(N^2 * T)。因为对于每个时间步 t（共 T 步），需要计算每个状态 s（共 N 个）的 δ_t(s)，每个计算需要遍历前一时间步的所有状态 s'（共 N 个），因此总操作数为 T * N * N = O(N^2 T)。空间复杂度：O(N * T)，因为需要存储每个时间步每个状态的 δ 和 ψ（或仅存储 ψ 用于回溯，δ 可滚动数组优化到 O(N)，但回溯需要 O(N*T) 存储 ψ）。若使用滚动数组且不回溯，空间可降为 O(N)。

复杂度21. 给定一个长度为 n 的 DNA 序列，使用哈希表统计所有长度为 k 的 k-mer 频次。请分析该算法的时间复杂度和空间复杂度（用 n 和 k 表示），并说明当 k 较小时空间复杂度可如何优化。
参考答案
时间复杂度：需要遍历序列一次，共 n-k+1 个 k-mer，每个 k-mer 的哈希计算和哈希表插入/更新平均为 O(k)（若逐字符计算哈希）或 O(1)（若使用滚动哈希）。因此总时间复杂度为 O((n-k+1)*k) ≈ O(nk)；若采用滚动哈希，则平均为 O(n)。空间复杂度：最坏情况下所有 k-mer 均不同，哈希表存储 n-k+1 个键，每个键长度为 k，因此空间复杂度为 O((n-k+1)*k) ≈ O(nk)。当 k 较小时，k-mer 种类最多为 4^k，可使用长度为 4^k 的数组直接计数，空间复杂度为 O(4^k)，当 4^k 远小于 nk 时更优；也可使用 2-bit 编码将每个 k-mer 压缩为整数，降低存储开销。

简答25. 简述 NGS 变异检测中“局部重比对（local realignment）”和“单倍型组装（haplotype assembly）”的基本思想，并说明它们主要解决什么问题。
参考答案
局部重比对：在初步比对后，对候选 indel 附近区域重新进行比对，使 reads 在该区域内的 gap 和错配更符合真实变异，减少因独立比对造成的假阳性/假阴性。单倍型组装：在候选变异区域将 reads 按重叠关系组装成若干单倍型序列，再评估样本携带哪些单倍型，从而更准确判定复杂 indel、相邻 SNP 和组合变异。二者主要解决 reads 在 indel 附近比对不准确、复杂变异难以用单点比对表达的问题。
算法设计26. 给定一批双端 NGS reads 和一个参考基因组，请设计一个基于种子-扩展（seed-and-extend）的快速比对算法流程，用于将 reads 定位到参考基因组。要求写出伪代码或流程，并说明如何处理双端约束和简单错配。
参考答案
流程：1）对参考基因组构建 k-mer 索引（如哈希表：k-mer -> 位置列表）；2）对每条 read 或 read pair，提取若干种子 k-mer，查询索引得到候选参考位置；3）对候选位置进行扩展比对，允许有限错配/indel，计算得分；4）保留高分比对；5）对双端 reads，要求两条 read 的比对位置在同一条染色体、方向合理、插入片段长度在预期范围内；6）输出最优比对及 MAPQ。伪代码：buildIndex(ref, k); for each readPair: seeds = extractSeeds(read1, read2); candidates = queryIndex(seeds); best = null; for each candidate: aln1 = extendAlign(read1, ref, candidate); aln2 = extendAlign(read2, ref, candidate); if validPair(aln1, aln2): score = score(aln1)+score(aln2); if score > best.score: best = (aln1, aln2); output best。
踩分点：踩分点：1）参考基因组 k-mer 索引构建；2）种子查询得到候选位置；3）扩展比对并允许错配/indel；4）双端方向、距离、同染色体约束；5）打分与最优比对选择；6）输出比对结果/质量值。
算法设计27. 请设计一个基于 de Bruijn 图的 NGS 短读长组装算法流程，输入为 reads 和 k 值，输出为 contigs。要求写出伪代码或流程，并说明如何处理错误 k-mer、分支和重复区域。
参考答案
流程：1）遍历所有 reads，统计每个 k-mer 的出现次数；2）根据 k-mer 频谱和覆盖度阈值过滤低支持度 k-mer，或先做 reads 纠错；3）构建 de Bruijn 图：每个 (k-1)-mer 为节点，每个 k-mer 为一条有向边；4）简化图：合并入度=出度=1 的节点，去除短死端、气泡和低覆盖边；5）在图中寻找 contigs，通常从分支节点或端点出发，沿唯一路径延伸；6）输出长度超过阈值的 contigs。伪代码：countKmers(reads); filterLowSupportKmers(); graph = buildDeBruijnGraph(kmers); simplifyGraph(graph); contigs = []; for each node in graph: if isBranchOrTip(node): path = walkUniquePath(node); if length(path) >= minLen: contigs.append(path); output contigs。
踩分点：踩分点：1）k-mer 统计与低支持度过滤/纠错；2）de Bruijn 图节点和边定义正确；3）图简化（合并唯一路径、去气泡/死端）；4）从分支/端点遍历生成 contigs；5）处理重复区域时说明分支和覆盖度限制；6）输出 contigs。
复杂度28. 设参考基因组长度为 G，reads 数量为 N，每条 read 长度为 L，k-mer 长度为 k。若使用哈希表索引参考基因组所有 k-mer，并对每条 read 提取所有 k-mer 进行查询，请分析该 seed-and-extend 比对流程在理想情况下的时间复杂度和空间复杂度。
参考答案
空间复杂度：参考基因组 k-mer 索引需要存储约 G 个 k-mer 及其位置，哈希表空间为 O(G)。时间复杂度：构建索引为 O(G)；对每条 read 提取 L-k+1 个 k-mer，每个 k-mer 哈希查询平均 O(1)，因此每条 read 查询种子平均 O(L)；N 条 reads 总查询为 O(NL)。若每个种子平均命中 c 个候选位置，则扩展验证总代价约为 O(NLc)，理想情况下 c 为常数，因此总时间复杂度为 O(G + NL)。若考虑最坏情况，某些重复 k-mer 可能命中大量位置，查询和扩展代价会显著增加。
