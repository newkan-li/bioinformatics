# 生物信息学 · 复试学习网页

陈铭《生物信息学》第三版（科学出版社）逐章详解，用于考研复试备考（如首都师范大学 0710J7 生物信息学 / 027003 生物信息学）。

概念学习 + 本页自测 + 全题型练习 + 错题本 + 间隔复习 + 闪卡 + 模拟测验 + 术语表。

覆盖全书 14 章：生物信息学概念与发展史、生物学数据库及其检索、序列比对原理、蛋白质结构预测与分析、真核生物基因组的注释、转录组学、非编码RNA、蛋白质组学、系统生物学、合成生物学、分子进化与系统发育、统计学习与推理、生物信息学编程基础、新一代测序技术及其应用。

本地运行：`python3 -m http.server 8000`，浏览器打开 http://localhost:8000/
