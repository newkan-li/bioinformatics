第一章 生物信息学的概念及发展历史

  1. 必背 生物信息学的定义：综合运用数学、计算机科学和生物学工具，对生物大分子序列及相关信息进行获取、加工、存储、检索、分析和解释的学科 p1 →
  2. 必背 生物信息学产生的背景：人类基因组计划(HGP)等大规模测序产生海量数据，需要计算手段处理 p1 →
  3. 高频 生物信息学两大核心任务：数据管理(数据库)与数据分析(算法与工具) p1 →
  4. 了解 中国生物信息学重要机构：北京大学生物信息中心、中国科学院生物物理所、上海生物信息技术研究中心等 p2 →
  5. 高频 生物信息学发展史上的里程碑：DNA双螺旋结构(1953)、蛋白质序列测定、GenBank/EMBL/PDB等数据库建立 p3 →
  6. 必背 人类基因组计划(HGP)：1990年启动，2001年草图，2003年完成，推动生物信息学飞跃发展 p4 →
  7. 高频 其他重要基因组计划：国际HapMap计划、ENCODE计划、千人基因组计划 p4 →
  8. 必背 生物信息学研究领域：序列比对、基因识别与注释、分子进化、蛋白质结构预测、基因表达谱分析、系统生物学等 p5 →
  9. 高频 生物信息学主要应用之一：生物数据库建设与整合，如核酸数据库、蛋白质数据库、专用数据库 p6 →
  10. 高频 数据挖掘在生物信息学中的应用：从海量生物数据中提取隐藏规律与知识 p6 →
  11. 高频 基因组自动注释：利用算法自动识别基因及功能元件；比较基因组学：通过物种间基因组比较揭示保守元件与进化关系 p7 →
  12. 必背 蛋白质结构预测：从氨基酸序列预测三维结构，包括同源建模、折叠识别、从头预测等方法 p8 →
  13. 高频 蛋白质互作(PPI)网络与生物系统模拟：构建互作网络，模拟细胞过程与系统行为 p8 →
  14. 高频 代谢网络建模：重建代谢通路，进行通量平衡分析等；计算进化生物学：分子钟、系统发生树构建 p9 →
  15. 高频 生物信息学面临的挑战：数据爆炸与异质性、算法效率、多组学整合、标准化与可重复性等 p10 →
  16. 高频 生物信息学未来展望：精准医学、单细胞测序、人工智能与深度学习在生物信息学中的应用 p10 →

第三章 序列比对原理

  2. 必背 字符编辑操作：替换、插入、删除；双序列比对本质是通过编辑操作将一条序列变为另一条序列，并寻找最优比对 p41 →
  3. 必背 全局比对（Needleman-Wunsch算法）与局部比对（Smith-Waterman算法）的递归算法思想、动态规划填表与回溯 p42 →
  4. 必背 相似性、同一性与同源性的区别；直系同源与旁系同源的概念及生物学意义 p43 →
  5. 高频 序列比对打分的目的：区分真实比对与随机匹配；打分矩阵概念：匹配/错配得分、空位罚分 p44 →
  6. 高频 DNA打分矩阵与氨基酸打分矩阵的差异；氨基酸打分矩阵需考虑理化性质与进化替换频率 p45 →
  7. 必背 PAM打分矩阵：基于进化模型构建，PAM1表示1%氨基酸发生替换；PAM值选择与序列相似度关系 p46 →
  8. 必背 BLOSUM打分矩阵：基于局部比对块构建，BLOSUM62为默认常用矩阵；与PAM矩阵的构建思想差异 p47 →
  9. 高频 不同打分矩阵对双序列比对结果的影响；根据序列相似度选择合适矩阵 p48 →
  10. 高频 仿射空位罚分：空位打开罚分与空位延伸罚分；dotplot算法原理与用途 p49 →
  11. 高频 dotplot算法特点：直观显示重复、倒置、插入缺失；动态规划算法是双序列比对的核心算法 p50 →
  12. 必背 动态规划算法计算示例：打分矩阵填充、最优路径回溯、全局/局部比对得分计算 p51 →
  13. 必背 BLAST算法原理：种子搜索、延伸、E值评估；BLAST特点：速度快、启发式、适合数据库搜索 p52 →
  14. 高频 FASTA程序功能；BLAST工具分类：blastn、blastp、blastx、tblastn、tblastx p53 →

  17. 必背 多序列比对概念与应用：保守区识别、系统发育分析、引物设计；常用算法：渐进比对、迭代比对 p56 →
  18. 高频 ClustalX/W多序列比对工具及操作步骤：序列输入、参数设置、比对运行、结果输出 p57 →

第四章 蛋白质结构预测与分析

  1. 必背 蛋白质结构组织层次：一级结构→二级结构→超二级结构→结构域→三级结构→四级结构；明确各级定义与相互关系 p60 →
  2. 必背 α螺旋：每圈3.6个残基，螺距0.54 nm，上升0.15 nm/残基；氢键为n与n+4残基间C=O…H-N；常见螺旋破坏者Pro、Gly p61 →
  3. 高频 β折叠：平行/反平行；β转角常见类型I、II、I'、II'，常含Gly、Pro；无规卷曲功能；超二级结构基序如βαβ、βββ、αα、β发夹 p62 →
  4. 必背 结构域：独立折叠单元，常与功能相关；三级结构为整条链空间构象；四级结构为亚基缔合；区分结构域与亚基 p63 →
  5. 高频 SCOP2：基于结构域进化关系分类，层级为Class→Fold→Superfamily→Family→Protein→Species；与SCOP区别 p64 →
  6. 高频 CATH分类：Class、Architecture、Topology、Homologous superfamily；PDBsum提供结构总结；实验测定方法：X射线晶体学、NMR、冷冻电镜 p65 →
  7. 高频 NMR测定溶液结构，适合小蛋白，可测动态；冷冻电镜适合大复合物，近原子分辨率；X射线晶体学需晶体，分辨率高 p66 →
  8. 高频 结构比对应用：结构分类、功能注释、进化分析、模建评估；基本原理：残基对应与空间叠合，最小化RMSD p67 →
  9. 高频 结构比对打分函数：RMSD、TM-score、GDT-TS、Z-score；CE算法基于组合扩展，先对齐片段再组合 p68 →
  10. 了解 多结构比对：MSTA，用于识别保守核心、构建结构谱；常用方法：MUSCLE、M-Coffee、DALI、CE、TM-align p69 →
  11. 高频 DALI：基于距离矩阵比对，适合远缘同源；CE：基于片段组合扩展，适合局部相似；两者均为经典结构比对方法 p70 →
  12. 高频 TM-align：基于TM-score的启发式迭代比对，不依赖序列，适合全局结构相似；特殊策略：柔性比对、多域比对 p71 →
  13. 必背 同源模建流程：模板搜索→序列比对→骨架构建→侧链安装→模型优化与评估；适用于序列同源性>30% p72 →
  14. 高频 侧链构象预测：旋转异构体库；模型评估：Ramachandran图、Verify3D、ProSA、QMEAN；循环精修：能量最小化、分子动力学 p73 →
  15. 必背 折叠识别：Threading，四步流程：序列-结构比对→打分函数→折叠库搜索→模型构建；适用于无同源模板 p75 →
  16. 高频 从头计算法：基于物理能量函数和构象搜索；QUARK：基于片段组装，适用于小蛋白；不依赖模板 p76 →
  17. 必背 I-TASSER：基于Threading+片段组装+原子模拟，CASP常胜；二级结构预测三代方法：PSSM、HMM、深度学习（如PSIPRED、DeepCNF） p77 →
  18. 高频 结构预测评价：CASP、CAMEO；指标：GDT-TS、TM-score、RMSD、Z-score；总体情况：同源模建最准，从头计算仍难 p78 →
  19. 高频 蛋白质对接：预测复合物结构；刚性对接、柔性对接；打分函数：形状互补、静电、氢键、疏水；应用：药物设计 p79 →
  20. 高频 ZDOCK：基于FFT的刚性对接；GRAMMX：基于模板的柔性对接；HADDOCK：基于实验约束的柔性对接，适合生物大分子 p80 →
  21. 必背 利文索尔悖论：蛋白质折叠不是随机搜索，而是有路径的；折叠漏斗模型解释快速折叠 p81 →
  22. 高频 折叠理论模型：框架模型、疏水塌缩模型、核化模型、漏斗模型；能量景观理论 p82 →
  23. 必背 构象病：蛋白质错误折叠导致，如阿尔茨海默病（Aβ）、帕金森病（α-synuclein）、疯牛病（PrP）、囊性纤维化（CFTR） p83 →

第五章 真核生物基因组的注释

  1. 必背 基因组注释的目标与内容：识别基因组中的蛋白质编码基因、RNA基因、重复序列、假基因等元件，并注释其结构、功能与位置；区分结构注释与功能注释。 p85 →
  2. 必背 蛋白质编码基因预测三种策略：基于证据（同源比对/EST/cDNA）、从头预测（ab initio）、整合注释；基于证据注释依赖外源证据，如转录本比对和蛋白质同源比对。 p86 →
  3. 高频 反式比对（transitive alignment）与基于证据注释的弱点：证据不完整、可变剪接、非编码外显子、物种特异性、测序错误和污染可导致错误注释。 p87 →
  4. 高频 从头预测与重新基因预测：从头预测依赖统计模型（如HMM、隐马尔可夫模型）和信号（启动子、剪接位点、polyA信号）；重新基因预测用于修正已有注释。 p88 →
  5. 必背 自动整合注释系统：如EVM、GLEAN、JIGSAW、Maker等，整合多种证据和预测结果，输出一致性基因集；权重设置影响整合结果。 p89 →
  6. 高频 RNA基因注释概述：包括tRNA、rRNA、snRNA、snoRNA、miRNA、lncRNA等；常用工具如tRNAscan-SE、RNAmmer、Rfam、Infernal。 p90 →
  7. 高频 非编码RNA注释与重复序列概述：ncRNA参与调控、剪接、翻译等；重复序列包括串联重复和散在重复（转座元件），占真核基因组很大比例。 p91 →
  8. 必背 转座元件鉴定方法与RepeatMasker：基于同源库和de novo预测；RepeatMasker使用Repbase库进行屏蔽和分类；输出类型、位置、拷贝数。 p92 →
  9. 高频 假基因分类与鉴定流程：分为加工型假基因、未加工型假基因、伪加工型假基因；鉴定依据序列相似性、中断ORF、缺乏启动子/剪接位点等。 p93 →
  10. 高频 黄瓜基因组EVM基因预测流程与蛋白质比对：EVM整合从头预测、转录本比对和蛋白质同源证据；蛋白质比对使用BLASTX/Exonerate等。 p94 →
  11. 高频 EVM整合预测、基因过滤与同源基因分析：过滤短基因、低置信基因；同源基因分析用于功能注释和比较基因组学。 p95 →
  12. 了解 黄瓜KEGG代谢通路注释与RNA基因注释：KEGG注释揭示代谢通路；RNA基因注释包括tRNA、rRNA等，使用tRNAscan-SE、RNAmmer等。 p96 →
  13. 高频 黄瓜基因组ncRNA预测：tRNA、snoRNA、miRNA与snRNA；常用工具tRNAscan-SE、snoScan、miRBase、Rfam。 p97 →
  14. 高频 重复序列注释：串联重复与转座元件de novo库构建；串联重复用TRF，转座元件用RepeatModeler构建de novo库。 p98 →
  15. 必背 转座元件分类统计与假基因注释流程：转座元件分为Class I（逆转座子）和Class II（DNA转座子）；假基因注释流程包括同源比对、ORF检测、分类。 p99 →
  16. 了解 假基因识别分类结果与思考题：假基因数量、类型分布；思考题涉及注释策略选择、证据权重、假基因功能等。 p100 →
